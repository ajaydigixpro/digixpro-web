### 1. 5-LAYER HYBRID ROUTING PIPELINE

1. **Layer 1: Tier-0 Deterministic Precedence**: Checks explicit capabilities (SEO > Web, Audit Intake, Booking, Handoff, Pricing, Objection).
2. **Layer 2: Text Normalization**: Lowercasing, punctuation stripping, transliteration.
3. **Layer 3: ONNX Vector Embedding**: Encodes input into 384d vector space.
4. **Layer 4: 2-Stage Hierarchical k-NN Search**: Filters Stage 1 Family -> Stage 2 Intent.
5. **Layer 5: Score Margin & State Validation**: Verifies Top-1 vs Top-2 score margin ($>0.10$, $+0.10$ for high-risk).
